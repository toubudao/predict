# 预测追踪器 Prediction Tracker

一个用 Python 标准库（tkinter）写的桌面小程序：记录你的预测 → 到点自动弹窗让你判断对错 →
统计正确率 → 复盘失败原因，帮你像做投资复盘一样，持续校准自己的判断力。

## 运行方式

不需要安装任何第三方库，电脑上有 Python 3（自带 tkinter）即可：

```bash
python app.py
```

Windows / Mac 自带的 Python 一般都包含 tkinter；如果提示找不到 tkinter，
Linux 用户可以装一下：`sudo apt install python3-tk`（Ubuntu/Debian 举例）。

程序启动后会打开一个窗口，包含 4 个标签页。**程序需要一直开着**（可以最小化），
因为弹窗提醒是靠这个窗口的后台轮询触发的——每 30 秒检查一次有没有到期的预测。

## 功能说明

### 1. 新增预测
- 预测内容：你要预测的事情（比如"明天会议是否能按时召开"）
- 预测结果：你认为会发生什么
- 多久后验证：填数字 + 选单位（分钟/小时/天），到点会自动弹窗
- 信心程度：1-100，给自己的判断打个分（目前用于记录，后续可以扩展按信心区间统计准确率）
- 分类标签：方便以后按类别（如"工作""股票""人际关系"）统计正确率

### 2. 预测列表
- 查看所有预测及状态（待验证 / ✅正确 / ❌错误）
- 可以手动选中某条提前验证，或删除某条记录

### 3. 定时弹窗验证
- 到达设定时间，会自动弹出对话框问你"这个预测是否正确"
- 选"是" → 记录实际结果，标记为正确
- 选"否" → 记录实际结果 + 选择失败原因分类（信息不足/情绪化判断/外部突发因素/逻辑分析错误/
  时机判断错误/其他）+ 填写具体原因
- 选"取消" → 暂不判断，下次轮询会再次提醒

### 4. 统计
- 总预测数、待验证数、已验证数
- 总体正确率
- 按分类标签拆分的正确率，方便看出你在哪类事情上判断更准

### 5. 复盘
- 失败原因分布（按出现频率排序），一眼看出自己最常踩的坑
- 每条失败预测的详细记录：预测内容、预测结果、实际结果、失败原因

## 数据存储

所有数据保存在同目录下的 `predictions.json`，纯文本 JSON 格式，方便备份或用其他工具二次分析。
删除该文件即可清空所有记录。
